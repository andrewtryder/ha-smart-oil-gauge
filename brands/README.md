# Home Assistant Brands Contribution Package

This folder contains the branding assets prepared for submission to the official [home-assistant/brands](https://github.com/home-assistant/brands) repository.

## Contribution Requirements
Home Assistant requires custom integration branding assets to be submitted via Pull Request to `home-assistant/brands`.

### Directory Structure to Submit to `home-assistant/brands`:
```text
custom_integrations/smart_oil_gauge/
├── icon.png        (256x256 px)
├── icon@2x.png     (512x512 px)
├── logo.png        (256x256 / vector format)
└── logo@2x.png     (512x512 / vector format)
```

## How to Submit:
1. Fork [home-assistant/brands](https://github.com/home-assistant/brands).
2. Create directory `custom_integrations/smart_oil_gauge/` in your fork.
3. Copy the assets from `brands/custom_components/smart_oil_gauge/` into `custom_integrations/smart_oil_gauge/`.
4. Open a Pull Request on `home-assistant/brands` titled `Add Smart Oil Gauge integration branding`.
